# Місячний Корж

Уютная 2D-игра про магическое кафе, где коты в разных нарядах заказывают торты. TypeScript + Canvas 2D, без движка.

## Запуск

```bash
npm install      # один раз
npm run dev      # дев-сервер на http://localhost:8765, перезагружается при сохранении
npm run build    # проверка типов + сборка в один файл dist/index.html (открывается без сервера)
```

`npm run typecheck` только проверяет типы, без сборки.

## Структура кода (`src/`)

Аналогия с Unity: редактора сцен нет, сцены — это функции, которые каждый кадр рисуют всё заново.

| Папка | Что внутри | В терминах Unity |
|---|---|---|
| `main.ts` | Игровой цикл: `update(dt)` → `render()` каждый кадр | `Update()` главного объекта |
| `input.ts` | Мышь / тач / клавиатура, нажатия кнопок | Input System |
| `core/` | Канвас, время, математика, цвета, рисование, кнопки, частицы, тема UI | утилиты движка |
| `data/` | **Контент игры**: ингредиенты, палитры, коты, стихии, магазин, расписание открытий. Без логики. | ScriptableObjects |
| `game/` | Правила: модель торта, смешивание цветов, распознавание знаков, заказы, оценка, меню дня, сохранения, ход дня, `state.ts` (всё состояние) | игровая логика / менеджеры |
| `audio/` | Синтезатор звуков, эффекты, музыка | AudioSource / AudioMixer |
| `render/` | Отрисовка объектов: торт, коты, украшения, фон кафе, иконки, колбы, карточка заказа | префабы / спрайты |
| `kitchen/` | Кухня: `layout.ts` (координаты), `stations/` (по файлу на станцию: коржи, крем, глазурь, украшения, чары) | компоненты станций |
| `scenes/` | Экраны: титул, начало дня, зал, кухня, конец дня, финал, магазин, общий HUD | Scenes |

### Состояние

- `progress` (`game/state.ts`): то, что сохраняется (день, монеты, покупки, меню). Пишется в `localStorage`.
- `runtime` (`game/state.ts`): всё остальное (текущая сцена, торт в работе, анимации).

### Где что менять

- Новый вкус / украшение / крем: `data/ingredients.ts` и расписание открытий в `data/schedule.ts`.
- Новый кот-гость: облик в `data/cats.ts`, реплики в `data/catLines.ts` (на обоих языках). Новая шляпа / наряд — тип в `data/types.ts` (`CatHat`, `CatOutfit`) и `case` в `render/cat.ts`.
- «Особый» гость (заказывает только определённые цвета глазури и/или формы): поле `orderRule` в `data/cats.ts`, например `{ glazes: ['purple', 'plum', 'lilac'] }`. В дни, когда меню не позволяет такой торт, гость не приходит. Текстом правило не показывается — его видно по картинке заказа.
- Экран: игра раскладывается на логическом поле 1280×720 (`core/canvas.ts`). На экранах другой формы (телефоны шире 16:9) видно больше поля вокруг — это `view`. Фоны (стена, прилавок, кухонный стол, затемнения через `fillView()`) рисуются на весь `view`; кнопки и персонажи остаются внутри 1280×720 и вне выреза iPhone.
- Туториал (первые два гостя дня 1): шаги — в `scenes/tutorial.ts` (`STEPS`), тексты — `t().tutorial` в `data/strings.ts`. Каждый шаг засчитывается сам, когда игрок сделал действие; кнопка «Пропустити навчання» есть всегда. Отметка «пройдено» хранится отдельно от сохранения (`misiachnyi-korzh-tutorial`, `game/tutorial.ts`), «Нова гра» её сбрасывает.
- Реплики выбираются «из мешка» (`game/lines.ts`): пока не прозвучат все реплики списка, ни одна не повторится. Больше реплик в списке — реже повторы.
- Особые гости заказывают коржи, начинку и крем только своей палитры: если их нет в меню дня, полка коржей сама добавляет нужное (`shelfItems` в `stations/layers.ts`).
- **Особые гости** (Фея — с дня 1, Демон — 2, Янгол — 3, Вампір — 4, Самурай — 5, Культист — 6, первый день бесконечного режима): `SPECIAL_GUESTS` в `data/cats.ts`, поле `special` — тема кухни, своя палитра (в `data/palettes.ts` с `isSpecial: true`, обычным гостям не достаётся), своя магия и фирменное украшение (перчик / пёрышко / шоколадный кажан / суші / чорна свічечка / метелик), которое есть в каждом их заказе и выставляется на полку только для них. Каждый день приходит один особый гость (в день своего `firstDay` — обязательно), в бесконечном режиме — двое, всегда разные. Обычные гости за день не повторяются (повтор возможен, только если их меньше, чем мест). Очередь — `buildGuestQueue` (`game/flow.ts`). Платят больше (`PRICE.special` в `game/scoring.ts`).
- Пока особый гость в кафе (`activeGuestTheme()` в `game/state.ts`), играет его музыка (`audio/music.ts`: треки `dungeon`, `heaven`, `palace`, `shrine`, `cult`, `meadow`), а кухня превращается в его тему — она расходится кругом от торта (`runtime.kitchenThemeBlend`). Сами темы (стена, стол, подставка, летающие искры/перья/лепестки) — `render/kitchenThemes.ts`.
- Магия особых гостей (Темрява — знак «вихор» (Демон и Культист; спираль засчитывается с любым числом витков 1,5–3, с любой точки, в любую сторону, снаружи внутрь и изнутри наружу — `alternatives` у знака в `SIGN_SHAPES`), Світло — «крила» ∞, Кров — «ікла» W, Сакура — «гілочка» J, падають пелюстки; у Феи обычная магия природы): `GUEST_ELEMENTS` в `data/elements.ts`. На станции чар она появляется шестой карточкой только у своего гостя, и распознаются только знаки, которые видны на станции (`recognizeSign(points, allowed)`). Эффекты на торте — `render/magicEffects.ts`, звуки — `sfx.magic`.
- Новая цветовая палитра заказов: `data/palettes.ts`.
- Магия в оценке: важно только, та ли стихия. Любой распознанный знак накладывает её в полную силу, аккуратность рисунка не учитывается (на телефоне трудно нарисовать идеально). Чужая стихия — `WRONG_MAGIC_SCORE`.
- Оплата в `game/scoring.ts`: часть торта (форма, коржі, начинка, крем, глазур, прикраси, магія) считается сделанной верно от оценки `PART_RIGHT_SCORE`. Если верно меньше половины частей (или почти ничего нет, например только коржі) — гость не платит вовсе (`refused`, не больше 2♥). Если верно одна часть или ни одной — торт испорчен, штраф `RUINED_CAKE_FINE` монет (`penalty`, 1♥). Монеты не уходят ниже нуля.
- **Временно для тестирования:** с дня 8 (`SPECIALS_ONLY_FROM_DAY` в `game/flow.ts`) за день приходят только особые гости, все шесть по одному разу. Чтобы вернуть обычные дни, удалить эту проверку или поставить `Infinity`.
- Сколько украшений просят гости: `TOPPING_COUNTS` в `game/orders.ts` — по дням истории: в день 1 одного вида, 1–3 штуки; дальше иногда два вида, к дню 5 до 6 одного вида (при двух видах — до 4 каждого).
- Цены, чаевые, веса оценки: константы вверху `game/scoring.ts` (`WEIGHTS.speed` — насколько важна скорость).
- Терпение гостей (сколько секунд ждут торт, когда начинают нервничать): `PATIENCE` и `PATIENCE_LEVELS` в `game/patience.ts`. Полоска терпения убывает равномерно с момента, когда принят заказ (`patienceBarValue`); отметка-треугольник на ней (`PATIENCE_CALM_MARK`) показывает, где кончается спокойное время: дальше гость начинает нервничать и снижается оценка за скорость. На кухне гость и полоска терпения — в карточке заказа слева (`drawTicket` в `scenes/kitchen.ts`). Гости туториала не торопятся. Когда терпение кончилось (`updatePatience` возвращает `true` → `loseGuestPatience` в `game/flow.ts`), гость возвращается в зал злым (состояние `storming`): поднимает недоделанный торт над головой и бросает его в экран, и торт расплывается кляксой цвета глазури или крема. Если торта нет, гость просто уходит. Такой гость не платит. Тайминги — `STORM`, клякса — `SPLAT` в `scenes/hall.ts`, реплики — `t().stormWithCake` / `stormNoCake`.
- Гость в окошке на кухне (`game/guestReactions.ts`) смотрит туда, где игрок нажимает или тянет (`lookAt` из `input.ts`), а через ~2 с снова смотрит на игрока. На выбор он реагирует коротким выражением лица и значком: неверный крем или магия — удивление «!», неверный корж, начинка, глазурь или лишнее украшение — беспокойство «?», верный крем, глазурь или магия — иногда (`PLEASED_CHANCE`, 40%) одно из двух спокойных лиц без значка: глаза довольно прикрыты (`content`) или рот чуть приоткрыт от радости (`delighted`). Вызовы `judgeChoice` стоят в станциях, лицо «surprised» — в `render/cat.ts`.
- Характер гостя: у части котов `temper: 'angry'` в `data/cats.ts` (Барсик, Вусань, Булочка, Морок, Дідусь, Демон, Вампір, Самурай). Когда терпение на исходе или торт плохой, такие коты злятся (нахмуренное лицо, значок злости, шипение) и говорят свои реплики `angry` из `data/catLines.ts`; остальные грустят (слезинка, реплики `bad`). Если гость ждал слишком долго, он начинает с упрёка — обиженного или сердитого (`t().lateSad` / `lateAngry`, без родовых форм, их говорят все). Логика — `startReaction` в `scenes/hall.ts` и `patienceMood` в `game/patience.ts`.
- Уход довольного гостя: от 3♥ он мяукает на прощание, а после 5♥ ещё мурлычет (`sfx.purr`), идёт медленнее и оставляет за собой сердечки (`GOODBYE_MEOW_HEARTS`, `PERFECT_PURR_SECONDS` в `game/flow.ts`).
- Расположение на кухне: `kitchen/layout.ts`. Слева только заказ (`TICKET`: окно с гостем, имя, терпение, картинка торта). Всё остальное — в центре: коржі (переключатели формы `SHAPE_SWITCHES` + полка), крем и украшения на полке над тортом (`INGREDIENT_SHELF`, `drawIngredientShelf` в `kitchen/widgets.ts`), стихии строкой (`ELEMENT_ROW`: это рисунки на стене, а не кнопки; по нужному знаку бегает искра — `SIGN_TRACE` в `stations/magic.ts`; полка помощников на этой станции скрыта), зелья на своей полке. Предметы на полках (коржі, баночки, миски, блюдца) — `render/shelfItems.ts`. Главная кнопка станции, которую жмут во время работы с тортом («Полити», отмена коржа ↶), — справа от торта, под правым большим пальцем (`CAKE_SIDE_BUTTON`). Под ней — «Авто» помощника (`AUTO_BUTTON`), подальше от «Подати торт» в верхней панели. «Вилити» — внизу слева от котла (`EMPTY_CAULDRON_BUTTON`), далеко от «Полити». «Зняти всі» на станции украшений — справа сверху (`STATION_CONTROLS`). Всё это рисует метод `drawControls` у станции.
- Экран начала дня (`scenes/dayStart.ts`): в день 1 показывается всё меню, дальше — только то, что сегодня новое или вернулось, и то, что сегодня отдыхает. Две такие группы стоят рядом колонками. Размер плиток подбирается самый крупный, при котором всё влезает (`MENU_TILE`, `fitTileWidth`).
- Цвета и шрифты интерфейса: `core/theme.ts`.
- Новая станция кухни: файл в `kitchen/stations/`, реализующий интерфейс `Station`, плюс строка в `kitchen/stations/index.ts`.

### Языки (украинский и японский)

- Текущий язык — `core/language.ts`: `language()`, `setLanguage()`, `loc(...)`. Хранится отдельно от сохранения (ключ `misiachnyi-korzh-language`), при первом запуске берётся из языка браузера. Переключатель «УКР | 日本語» — на титульном экране.
- Тексты интерфейса — `data/strings.ts`, читаются как `t().newGame`, `t().dayTitle(day)`. У японской таблицы те же ключи, что у украинской: если что-то забыть, `typecheck` подскажет.
- Имена котов, ингредиентов, товаров — прямо в `data/`, в виде `{ uk: '…', ja: '…' }`; на экран — через `loc(cat.name)`. Реплики котов — `lines: { uk: {…}, ja: {…} }`.
- В японском нет пробелов, поэтому `wrapText` (`core/draw.ts`) переносит его по символам и не начинает строку с «、。！」».
- Японский шрифт — M PLUS Rounded 1c (Google Fonts, `index.html`); латиница и кириллица по-прежнему из Nunito / Comfortaa.

### Отладка

При `npm run dev` в консоли браузера доступны `__game.runtime`, `__game.progress` и `__game.stations` (например, `__game.progress.coins = 999`). В сборку этот объект не попадает.

`legacy/index.html` — исходная однофайловая версия, оставлена для сравнения.

### Текст на экране

Игра рассчитана на телефоны, поэтому поясняющего текста минимум (основы объясняет туториал), а шрифты крупные. Подписи в кнопках и на карточках сами уменьшаются, если не влезают (`drawFittedText` в `core/draw.ts`, не меньше 70% размера) — при переводе или новых длинных названиях проверять раскладку вручную не обязательно.
